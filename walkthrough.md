## The Problem It Solves

Millions of people struggle to maintain deep focus in the age of distractions. The Pomodoro Technique is clinically proven to improve focus and prevent burnout by working in structured intervals. FocusFlow brings this technique to life with beautiful design and practical tools.

---

## Features

| Feature | Description |
|---|---|
| ⏱️ **Pomodoro Timer** | Animated SVG ring countdown with Focus / Short Break / Long Break modes |
| 📋 **Task Manager** | Add, prioritize, track, and complete tasks with Pomodoro counts |
| 📊 **Focus Analytics** | Weekly bar chart, productivity score ring, session history |
| 🔥 **Streak Tracker** | Tracks your daily focus streak in the header |
| 🎵 **Ambient Sounds** | Rain, Forest, Café, Waves via Web Audio API |
| ⚙️ **Settings** | Customize all durations, daily goal, notifications, and sounds |
| 💾 **Persistence** | Everything saved to `localStorage` — survives page refresh |
| ⌨️ **Keyboard Shortcuts** | Space = play/pause, R = reset, S = skip |
